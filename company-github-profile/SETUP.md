# GitHub organization profile setup

This package contains an organization profile README and the supplied company logo.

To display it on the Exploree Solutions GitHub organization overview:

1. Create or open the public `Exploree-Solutions/.github` repository.
2. Add `profile/README.md` from this package at the same path.
3. Add `assets/exploree-logo.png` from this package at the same path.
4. Commit both files to the repository's default branch.

Keep the folder structure intact so the relative logo link resolves. The supplied logo is preserved unchanged, including its white background and surrounding whitespace.

The profile omits unconfirmed contact details, launch claims, customer counts and proposed partnership commercial terms.
